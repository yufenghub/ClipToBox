# ClipToBox

检测剪贴板中新截图并粘贴到允许的 AI 对话页；可选择仅当前标签页或广播到所有 AI 标签页。

## GitHub Pages

本仓库包含 ClipToBox 的官方网站和隐私政策页面。

- 首页：`https://yufenghub.github.io/ClipToBox/`
- 隐私政策：`https://yufenghub.github.io/ClipToBox/privacy.html`

### 开启 GitHub Pages

1. 打开仓库的 **Settings**。
2. 左侧进入 **Pages**。
3. `Build and deployment` → `Source` 选择 **Deploy from a branch**。
4. Branch 选择 **main**，Folder 选择 **/(root)**。
5. 点击 **Save**。
6. 等待 GitHub 完成部署。

## 默认支持

- ChatGPT
- Gemini
- Claude
- DeepSeek
- Qwen
- 豆包

## 隐私

ClipToBox 不运行用于收集剪贴板图片或聊天内容的开发者数据服务器。详见 [Privacy Policy](privacy.html)。
